**GhostWorld** — это мощный инструмент для проверки ПК на наличие читов, стороннего ПО, макросов и следов их использования. Написан на чистом PowerShell с использованием WPF для создания современного неонового интерфейса. Не требует установки сторонних библиотек или компиляторов — просто запусти `.bat` файл.

## ✨ Основные возможности

* 🎨 **Современный UI/UX** — темная тема, неоновый акцент, кастомные анимации и скроллбары. Никакого уродливого консольного дизайна.
* 🚀 **Глубокая проверка** — сканирование AppData, Temp, Prefetch, реестра, планировщика задач и корзины.
* 🗑️ **Безопасное удаление** — встроенный менеджер, который не просто удаляет читы, а отправляет их в Корзину (на случай ошибки).
* 🧠 **AI-анализ JAR** — распаковка и анализ внутренностей Minecraft-модов на наличие вредоносного кода или чит-классов (Baritone, KillAura и т.д.).
* 📜 **Встроенные правила** — удобное окно с базой правил сервера, разбитое по разделам.
* 💉 **Инжектор** — возможность внедрения DLL в процесс Minecraft (для тестов или своих скриптов).
* ⚡ **Интеграция с Everything** — быстрый поиск подозрительных архивов.

| Раздел | Описание |

## 🚀 Как запустить

1. Скачай файл `GhostWorld.bat` из репозитория.
2. Нажми **ПКМ -> Запуск от имени Администратора** (обязательно, так как скрипт работает с процессами и системными папками).
3. Выбери язык (RU / UA / EN).
4. Пользуйся. Настройки (цвет акцента, шрифт) сохраняются в `%APPDATA%\GhostWorld\settings.json`.

> ⚠️ **Важно:** При первом запуске Windows SmartScreen или антивирус может ругаться на файл. Это ложное срабатывание, так как скрипт использует Win32 API для работы с процессами. Можешь смело добавлять в исключения.
